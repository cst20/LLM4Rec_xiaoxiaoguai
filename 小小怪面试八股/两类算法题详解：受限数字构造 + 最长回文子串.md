
# 算法小小怪笔记秋招篇：两道非hot100的算法题
数位DP和最长回文子串

### 一、题目一：用数组 `{2,4,9}` 组成小于 `23311` 的最大数字


> 给定一个数字 `23311`，和一个数组 `{2,4,9}`，找到用这个数组（可以重复使用）组成的小于这个数字的最大数字。


这个题的核心是：从高位到低位，尽量让当前位大，但不能让整体超过目标数。

数字大小比较，本质就是从左到右比较。

例如：

```text
23311
22999
```

第一位一样，第二位 `2 < 3`，所以后面不管怎么填，`22999` 一定小于 `23311`。
因此一旦某一位已经严格小于目标数字，后面都应该填可用数字中的最大值。

假设：

```text
N = 23311
digits = [2, 4, 9]
```

把 `digits` 排序：

```text
[2, 4, 9]
```

然后从左到右构造。

每一位有三种情况：

---

##### 情况 1：可以选到等于目标当前位的数字

比如第一位目标是 `2`，digits 里有 `2`。

那么可以先选 `2`，继续往后走。

因为当前还没有变小，后面仍然受限制。

---

##### 情况 2：可以选到小于目标当前位的最大数字

比如第二位目标是 `3`，digits 里没有 `3`，但是有小于 `3` 的 `2`。

那就选 `2`，然后后面全部填最大数字。

```text
2 2 9 9 9
```

直接返回。

---

##### 情况 3：当前位没有任何数字可以选

比如目标当前位是 `1`，但是 digits 是 `{2,4,9}`，没有数字小于等于 `1`。

这时候当前位没法构造，必须回退到前面，把前面某一位变小。



##### 算法：贪心 + 回退

假设：

```text
N = "23311"
digits = ['2', '4', '9']
```

步骤：

1. 对 digits 排序。
2. 从左到右尝试构造和 N 一样长的数字。
3. 如果当前位可以选等于目标位的数字，就先选等于的，继续。
4. 如果当前位可以选小于目标位的最大数字，选它，然后后面全填最大 digit，返回。
5. 如果当前位没有合法选择，则向前回退。
6. 回退时，找到一个之前的位置，把它替换成“比原来小的最大 digit”，然后后面全填最大 digit。
7. 如果回退到最前面都不行，则返回长度少一位的最大数。

```text
function solve(N, digits):
    sort digits ascending
    ans = empty array

    for i from 0 to len(N)-1:
        cur = N[i]

        if cur exists in digits:
            ans.append(cur)
            continue

        smaller = digits 中小于 cur 的最大数字

        if smaller exists:
            ans.append(smaller)
            后面全部填 digits 中最大数字
            return ans

        else:
            // 当前位无法选，必须回退
            从 ans 最后一位开始往前找：
                找到某一位 ans[j]
                看 digits 中是否存在比 ans[j] 小的最大数字
                如果存在：
                    ans[j] = 这个更小的数字
                    ans[j+1 ... end] 全部填最大数字
                    return ans

            // 如果所有位都无法回退
            return 长度 len(N)-1 的全部最大数字
```

### 二、最长回文子串

题目：

> 给定一个字符串 `s`，找到它的最长回文子串。注意子串必须连续，子序列不要求连续。


##### 方法一：动态规划 DP

```text
dp[i][j] 表示 s[i...j] 是否是回文串
```


```text
dp[i][j] = s[i] == s[j] and (j - i < 3 or dp[i+1][j-1])
```



```python
def longest_palindrome_dp(s: str) -> str:
    n = len(s)
    if n < 2:
        return s

    dp = [[False] * n for _ in range(n)]

    start = 0
    max_len = 1

    # 枚举子串长度
    for length in range(1, n + 1):
        for i in range(0, n - length + 1):
            j = i + length - 1

            if s[i] == s[j] and (length <= 3 or dp[i + 1][j - 1]):
                dp[i][j] = True

                if length > max_len:
                    start = i
                    max_len = length

    return s[start:start + max_len]
```

复杂度： `O(n^2)` 

### 中心扩展


回文串有一个中心。

例如奇数长度回文：

```text
"aba"
```

中心是：

```text
b
```

偶数长度回文：

```text
"abba"
```

中心在两个 `b` 中间。

所以回文可以分成两类：

1. 奇数长度回文：一个字符作为中心。
2. 偶数长度回文：两个字符之间作为中心。

我们枚举所有中心，然后向两边扩展。

---

##### 奇数回文示例

```text
s = "babad"
```

以 `s[1] = 'a'` 为中心：

```text
b a b
  ^
```

向左右扩展：

```text
left = 0, right = 2
s[0] == s[2] == 'b'
```

得到：

```text
"bab"
```

---

##### 偶数回文示例

```text
s = "cbbd"
```

以两个 `b` 中间为中心：

```text
c b b d
  ^ ^
```

向左右扩展：

```text
left = 1, right = 2
s[1] == s[2] == 'b'
```

得到：

```text
"bb"
```

---

##### 为什么中心数量是 `2n - 1`？

字符串长度为 `n`。

有 `n` 个字符中心：

```text
0, 1, 2, ..., n-1
```

还有 `n - 1` 个字符间隙中心：

```text
0和1之间
1和2之间
2和3之间
...
```

所以总中心数：

```text
n + (n - 1) = 2n - 1
```

---

##### 中心扩展代码

```python
def longest_palindrome_center(s: str) -> str:
    n = len(s)
    if n < 2:
        return s

    start = 0
    max_len = 1

    def expand(left: int, right: int):
        """
        从 left 和 right 开始向两边扩展。
        返回扩展后的回文子串左右边界。
        """
        while left >= 0 and right < n and s[left] == s[right]:
            left -= 1
            right += 1

        # 循环结束时，left 和 right 已经越过了合法回文边界
        # 所以真实回文是 s[left+1 ... right-1]
        return left + 1, right - 1

    for i in range(n):
        # 奇数长度回文
        l1, r1 = expand(i, i)
        len1 = r1 - l1 + 1

        if len1 > max_len:
            start = l1
            max_len = len1

        # 偶数长度回文
        l2, r2 = expand(i, i + 1)
        len2 = r2 - l2 + 1

        if len2 > max_len:
            start = l2
            max_len = len2

    return s[start:start + max_len]
```


#####  中心扩展复杂度

有 `O(n)` 个中心。

每个中心最坏向两边扩展 `O(n)` 次。

所以：

```text
时间复杂度：O(n^2)
空间复杂度：O(1)
```



### 方法三：Manacher 算法，O(n)


Manacher专门用来在线性时间内求最长回文子串。

##### 从中心扩展到马拉车

以字符串：

```text
aaaaaaaaaa
```

为例，每个中心都可以扩展很远。

中心扩展会重复比较很多次。

例如：

```text
中心 4 扩展很多
中心 5 也扩展很多
中心 6 也扩展很多
```

大量信息被重复计算。

Manacher 的关键就是：

> 利用已经计算过的回文半径，避免重复扩展。


Manacher 做两件事：

1. 预处理字符串，让奇数回文和偶数回文统一。
2. 维护当前最靠右的回文区间，用镜像信息加速计算。

---

##### 先预处理字符串

为什么要预处理？

因为回文分奇数和偶数。

奇数回文：

```text
aba
```

中心是字符。

偶数回文：

```text
abba
```

中心是两个字符之间。

为了统一处理，我们在字符之间插入 `#`。

例如：

```text
s = "abba"
```

变成：

```text
# a # b # b # a #
```

写成字符串：

```text
"#a#b#b#a#"
```

这样原来的偶数回文 `"abba"` 就变成了一个奇数长度回文：

```text
#a#b#b#a#
```

中心是中间的 `#`。

---

##### 加边界符

为了避免扩展时越界，通常再加两个特殊边界符：

```text
^
$
```

例如：

```text
s = "abba"
```

变成：

```text
^ # a # b # b # a # $
```

即：

```text
"^#a#b#b#a#$"
```

其中：

* `^` 只放在最左边
* `$` 只放在最右边
* 它们不会和普通字符相等

这样扩展时不需要每次判断边界。

---

##### Manacher 中的数组 `p`

对于预处理后的字符串 `t`：

```text
t = "^#a#b#b#a#$"
```

定义：

```text
p[i] = 以 t[i] 为中心的最长回文半径
```

这里的半径指的是：

> 在预处理字符串里，向左/右最多能扩展多少步。

例如：

```text
s = "abba"
t = "^#a#b#b#a#$"
```

最长回文中心是中间的 `#`。

对应的 `p[i] = 4`。

这个 `4` 刚好也是原字符串中最长回文的长度：

```text
"abba"
```

长度是 4。

这是 Manacher 预处理的一个很舒服的性质：

```text
p[i] 的最大值 = 原字符串最长回文子串长度
```

---

#####  Manacher 维护两个变量

Manacher 扫描每个位置 `i`，同时维护：

```text
center
right
```

含义是：

```text
center = 当前已知最靠右回文串的中心
right  = 当前已知最靠右回文串的右边界
```

也就是说，当前有一个回文区间：

```text
[center - p[center], center + p[center]]
```

它的右端点是：

```text
right = center + p[center]
```

我们希望 `right` 尽量靠右。

---

#####  镜像位置 mirror

如果当前正在处理位置 `i`，并且 `i` 在当前最右回文区间内部：

```text
i < right
```

那么 `i` 关于 `center` 的镜像位置是：

```text
mirror = 2 * center - i
```

画一下：

```text
left          mirror      center       i          right
 |--------------|-----------|----------|-------------|
```

因为整个区间是回文，所以 `mirror` 附近的信息可以帮助我们推断 `i` 附近的信息。

---

##### Manacher 的关键转移

如果：

```text
i < right
```

那么：

```text
p[i] 至少可以先取 min(right - i, p[mirror])
```

也就是：

```text
p[i] = min(right - i, p[mirror])
```

为什么取最小值？

因为 `mirror` 的回文半径可能超过当前大回文区间的左边界。

我们只能保证在当前大回文区间内部的部分是对称的。

所以不能直接无脑用：

```text
p[i] = p[mirror]
```

而要用：

```text
min(right - i, p[mirror])
```


#####  Manacher 代码

```python
def longest_palindrome_manacher(s: str) -> str:
    if not s:
        return ""

    # 预处理
    # 例如 s = "abba"
    # t = "^#a#b#b#a#$"
    t = "^#" + "#".join(s) + "#$"

    n = len(t)
    p = [0] * n

    center = 0
    right = 0

    max_len = 0
    center_index = 0

    for i in range(1, n - 1):
        mirror = 2 * center - i

        # 如果 i 在当前最右回文区间内，可以用镜像信息初始化
        if i < right:
            p[i] = min(right - i, p[mirror])

        # 尝试继续扩展
        while t[i + 1 + p[i]] == t[i - 1 - p[i]]:
            p[i] += 1

        # 如果以 i 为中心的回文超过了 right，更新 center 和 right
        if i + p[i] > right:
            center = i
            right = i + p[i]

        # 记录最长回文
        if p[i] > max_len:
            max_len = p[i]
            center_index = i

    # 将预处理字符串中的位置映射回原字符串
    start = (center_index - max_len) // 2

    return s[start:start + max_len]
```


###  TLDR
| 方法       |    时间复杂度 |    空间复杂度 | 难度 |    面试推荐度 |
| -------- | -------: | -------: | -: | -------: |
| DP       | `O(n^2)` | `O(n^2)` | 中等 | 可以写，但空间大 |
| 中心扩展     | `O(n^2)` |   `O(1)` | 简单 |  最推荐常规写法 |
| Manacher |   `O(n)` |   `O(n)` | 较难 |    高阶加分项 |

如果面试官只是问：

> 最长回文子串怎么做？

优先写：

```text
中心扩展
```

因为它代码短、空间优、容易讲清楚。

如果面试官追问：

> 有没有 O(n)？

再讲 Manacher。

可以这样回答：

```text
常规做法我会用中心扩展，枚举 2n-1 个中心，每个中心向两边扩展，时间 O(n^2)，空间 O(1)。
如果要求线性时间，可以用 Manacher。它通过插入分隔符统一奇偶回文，并维护当前最右回文边界，利用镜像位置复用已计算的回文半径，整体 O(n)。
```
